Foundations

What is a stream cipher?

A symmetric cipher that encrypts data a bit or byte at a time by combining it with a stream of pseudo-random values. Unlike a block cipher, it needs no fixed block size and no padding.

What is a keystream?

The pseudo-random sequence produced from the key. Sender and receiver generate the same keystream independently, so it is never transmitted.

What is symmetric encryption?

Encryption where both parties use the same secret key. The security of the system depends on keeping that key secret.

What is XOR?

Exclusive OR outputs 1 when its two input bits differ. Because (P ⊕ K) ⊕ K = P, applying the same keystream twice returns the original message, so encryption and decryption are the same operation.

Why do stream ciphers require careful keystream management?

If two messages use the same keystream, then C₁ ⊕ C₂ = P₁ ⊕ P₂. The key cancels out, and an attacker can often recover both messages from that value. So a key and frame value pair must never be reused for different data. A stream cipher also gives no integrity: flipping a ciphertext bit flips the same plaintext bit.

RC4

Why does RC4 use a 256-element array?

One entry for each possible byte value. The array is always a permutation of 0 to 255, and values read from it are used as indexes into it, which suits fast byte-oriented software.

What does KSA do?

The Key Scheduling Algorithm starts from the array 0, 1, …, 255 and makes 256 swaps chosen by the key. The result is a key-dependent permutation.

What does PRGA do?

The Pseudo-Random Generation Algorithm updates i and j, swaps S[i] and S[j], and outputs S[(S[i] + S[j]) mod 256]. The array keeps changing as output is produced.

Why is RC4 considered insecure?

Its output has statistical biases, especially in the first bytes, and WEP's use of related keys allowed key recovery. RFC 7465 prohibits RC4 in TLS.

A5/1

What is an LFSR?

A Linear Feedback Shift Register shifts its bits by one position per clock, and computes the new input bit as the XOR of selected positions called taps. It is cheap in hardware, but a single LFSR is predictable because its output is linear.

What is majority clocking?

Each register has one clocking bit. The cycle's majority value is the one held by at least two of those bits, and only registers matching it advance. So two or three registers move each cycle, and each moves with probability 3/4.

Why does A5/1 use three registers?

Together they hold 64 bits of state, and their outputs are combined with XOR. Irregular clocking makes each register's movement depend on the others, which removes the simple linear structure of a regularly clocked LFSR.

What is the GSM session key?

Kc is a 64-bit key that the SIM and the network derive during authentication, from the SIM's long-term secret and a random challenge. This lab uses sample keys only, and it does not implement GSM authentication.

What is the purpose of the frame count?

Mixing a frame-dependent COUNT into the registers gives every frame a different keystream under the same Kc. COUNT is derived from the TDMA frame number, but the two are different numbers.

Security limitations

  • Do not use these algorithms to protect real data. RC4 and A5/1 both have known practical weaknesses. A5/1 can be attacked with precomputed tables.
  • A5/1 is not end-to-end encryption. It protects only the GSM radio link between a handset and the base station.
  • Keystream reuse is fatal. Encrypting two messages with the same key and frame value reveals the XOR of the messages.
  • This is not a GSM implementation. It has no authentication, signalling or radio framing, and it does not connect to mobile networks. Use sample keys, never real SIM keys.

Message length with A5/1

  • Under 114 bits: one frame is generated, and the extra keystream bits go unused. Nothing is padded.
  • Exactly 114 bits: the whole sequence is used. Choose Binary bits to enter exact bit counts.
  • Over 114 bits: the message is split into segments of up to 114 bits. Each segment reinitializes the cipher with the next COUNT (mod 2²²). With an FN, the FN advances (mod 2715648), and each COUNT is derived from it. This is an educational convention, not GSM framing.

Computation stays on this machine, and keys and messages are not stored. RC4 and A5/1 are not recommended for protecting modern communications.
